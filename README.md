University Marketplace

A web platform for university student businesses to advertise and sell products without relying on WhatsApp groups.

## Problem it solves
University WhatsApp groups are flooded with business ads (food, tutoring, clothing, gadgets). This platform gives those small businesses a proper marketplace instead.

## Current status
**Week 1**: Database setup complete
**Week 2**: Building MVP (homepage, product listings, search)
**Week 3+**: User accounts, seller dashboard, monetization

## Tech stack
- **Backend**: ASP.NET Core 8.0 (C#)
- **Database**: SQL Server
- **Frontend**: HTML, CSS, JavaScript (Razor Pages)
- **IDE**: Visual Studio 2022
